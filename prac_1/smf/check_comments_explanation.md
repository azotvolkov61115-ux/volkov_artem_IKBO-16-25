# Объяснение скрипта `check_comments.sh`

## Назначение

Скрипт без аргументов проверяет первую строку файлов с расширениями `.c`, `.js` и `.py` только в текущей директории. Во вложенные папки он не заходит. Для каждого найденного файла скрипт выводит, содержит ли первая строка комментарий.

## Построчное объяснение

```bash
#!/bin/bash
```

Указывает, что файл должен выполняться с помощью интерпретатора Bash.

```bash
find . -maxdepth 1 -type f \\
    \( -name '*.c' -o -name '*.js' -o -name '*.py' \) -print0 |
```

Команда `find` ищет подходящие файлы:

- `.` — текущая директория;
- `-maxdepth 1` — не заходить во вложенные директории;
- `-type f` — выбирать только обычные файлы;
- `-name '*.c'` — файлы языка C;
- `-name '*.js'` — файлы JavaScript;
- `-name '*.py'` — файлы Python;
- `-o` означает «или»;
- `-print0` выводит имена файлов с нулевым разделителем, поэтому корректно обрабатываются имена с пробелами.

Символ `|` передаёт найденные файлы следующей части скрипта.

```bash
while IFS= read -r -d '' file; do
```

Цикл `while` последовательно читает найденные имена файлов и сохраняет текущее имя в переменную `file`.

- `IFS=` запрещает удалять пробелы в имени файла;
- `-r` запрещает Bash обрабатывать обратные слеши как специальные символы;
- `-d ''` указывает, что файлы разделяются нулевым символом.

```bash
    first_line=$(head -n 1 "$file")
```

Команда `head -n 1` получает первую строку текущего файла. Результат сохраняется в переменную `first_line`.

```bash
    extension="${file##*.}"
```

Из имени файла извлекается расширение. Например, для `program.py` результатом будет `py`.

```bash
    if [[ "$extension" == "py" && "$first_line" =~ ^[[:space:]]*# ]] ||
       [[ "$extension" != "py" && "$first_line" =~ ^[[:space:]]*(//|/\*) ]]; then
```

Условие проверяет, является ли первая строка комментарием.

Для Python проверяется символ `#` в начале строки. Выражение `^[[:space:]]*` разрешает наличие пробелов перед комментарием.

Для файлов C и JavaScript проверяются обозначения комментариев `//` и `/*`. Символ `#` для этих языков не используется, поэтому, например, строка `#include` в C не будет ошибочно принята за комментарий.

- `&&` означает «и»;
- `||` означает «или»;
- `[[ ... ]]` — условная конструкция Bash;
- `=~` выполняет проверку по регулярному выражению.

```bash
        echo "$file: первая строка содержит комментарий"
```

Если условие выполнилось, выводится имя файла и сообщение о наличии комментария в первой строке.

```bash
    else
        echo "$file: первая строка не содержит комментария"
```

Если условие не выполнилось, выводится сообщение об отсутствии комментария.

```bash
    fi
```

Завершает условную конструкцию `if`.

```bash
done
```

Завершает цикл `while`. После этого проверка всех найденных файлов заканчивается.

## Запуск

Перед первым запуском нужно сделать файл исполняемым:

```bash
chmod +x check_comments.sh
```

После этого скрипт запускается из текущей директории:

```bash
./check_comments.sh
```

Скрипт не принимает аргументы. Он проверяет только файлы `.c`, `.js` и `.py`, находящиеся непосредственно в текущей папке, из которой был запущен.
